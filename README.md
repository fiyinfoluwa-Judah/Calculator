
# 🍎 Apple-Style Calculator

A simple, interactive calculator inspired by the design of Apple's iPhone calculator, built using HTML, CSS, and JavaScript.

## 📸 About the Project

This project recreates the clean and minimal appearance of Apple's calculator, featuring a black background, rounded buttons, orange operators, and a responsive display.

It was created as a beginner-friendly web development project to practice front-end programming.

## ✨ Features

- Apple-inspired calculator design
- Addition, subtraction, multiplication, and division
- Percentage calculations
- Positive and negative number conversion
- Decimal number support
- Clear and reset functionality
- Keyboard input support
- Responsive layout for smaller screens
- Interactive button animations
- Error handling for division by zero

## 🛠️ Technologies Used

- **HTML5** — Structure of the calculator
- **CSS3** — Styling, layout, and animations
- **JavaScript** — Calculator logic and functionality

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your web browser.

You can also install the Live Server extension in VS Code and select **Open with Live Server** to run the calculator.
